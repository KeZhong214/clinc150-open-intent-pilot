# 课堂演示操作卡（60–90 秒）

## 上台前 30 秒

1. 打开 **PowerShell**，进入项目目录：
   ```powershell
   cd D:\code\intent-open-set
   ```
2. 双击 `start_demo.cmd`，或在 PowerShell 运行：
   ```powershell
   .\start_demo.ps1
   ```
3. 看到 `PREFLIGHT_OK` 和 `http://127.0.0.1:8509` 后再切到浏览器。
4. 若启动失败：不要重装、不要联网；直接使用 PPT 第 11 页截图和 `figures/gate8_2_demo_release.png` 备用。

## 固定设置

- **模型**：Qwen-Plain42-RejectOnly（固定，不切换）
- **模式**：离线模式（无 API）
- **页面**：浏览器打开 `http://127.0.0.1:8509`
- **开场点击**：`重置演示（新会话 DB）`

## 演示台词与操作

### ① 卡片状态（约 20 秒）

点击按钮：**① 查询 CARD-1002**

输入（如需手动）：`我的卡CARD-1002还没到`

预期：

- 意图 `card_arrival`，接受 `True`，分数约 `0.7766`，阈值 `0.4168`；
- 工具 `get_card_delivery_status`；
- 中文回复：运输中、未激活；
- 侧栏 DB：`CARD-1002` 为 `inactive / in_transit`。

讲解：路由模型先判断“能不能接”，再把已接受请求交给只读工具。

### ② 取消转账，先确认（约 35 秒）

点击按钮：**② 取消 TXN-2002**

预期：

- 意图 `cancel_transfer`，接受 `True`，分数约 `0.8177`；
- 系统要求明确确认；
- 侧栏 DB 仍为 `TXN-2002 pending`（**尚未取消**）。

在聊天框输入：`确认`

预期：

- 中文回复“已确认，转账 TXN-2002 已取消”；
- 工具记录出现 `cancel_transfer`；
- 侧栏 DB 变为 `cancelled`；
- 审计记录保留。

讲解：确认前不改变数据库；确认后才执行敏感工具。

### ③ OOS 备用（约 15 秒，可选）

点击：**③ OOS 备用**

预期：

- OOS / 不接受；
- 只调用 `handoff_to_human`；
- 不执行卡片或转账资金工具。

## 失败时切哪条线

| 现象 | 处理 |
|---|---|
| 没有启动 / 端口占用 | 用 PPT 第 11 页截图；不要现场调试 |
| 模型加载失败 | 用离线截图和已保存的工具轨迹 |
| 中文卡片没被接受 | 改用按钮 ①（固定短语 `我的卡CARD-1002还没到`）；不要临时换模型 |
| 确认后没有变化 | 检查是否输入“确认”；未确认时数据库保持 pending 是正确行为 |
| API 报错 | 保持离线模式；不在课堂上输入或展示 Key |
